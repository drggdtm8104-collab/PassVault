# PassVault

iPhone のホーム画面に追加して使う、自分専用のパスワード管理アプリ（PWA）です。

- データは **端末の中だけ** に、**暗号化して** 保存します。通信は一切しません。
- 開くには Face ID（設定で有効化）またはマスターパスワードが必要です。
- 暗号化バックアップを書き出し、PC のブラウザでも中身を確認できます。
- 非常用に、平文（TXT / CSV）での書き出しもできます。

安全設計の詳細は [SECURITY.md](SECURITY.md) を参照してください。

## 使い方（iPhone）

1. Safari で公開 URL（例：`https://<GitHubユーザー名>.github.io/PassVault/`）を開く
2. 共有ボタン →「ホーム画面に追加」
3. **ホーム画面のアイコンから** 開いて「新しく始める」
   - Safari のタブとホーム画面のアプリは保存場所が別です。必ずホーム画面から使ってください。
4. 設定 →「Face ID を有効にする」（任意）

### 入力のルール

- 追加するときに **種類**（ログイン／メール／銀行・カード／その他）を選ぶと、その種類に合った入力欄が出る。一覧の「表示」プルダウンで種類ごと・お気に入りに絞り込める
- **名前** は「X（仕事用）」のように、同じサービスが複数あっても区別できる付け方にする
- （ログインの場合）**ログイン ID** には、ログイン画面で実際に入力するもの（メールアドレス・ユーザー名・会員番号など）を入れる
- **登録メールアドレス** は、ログイン ID と別の場合だけ入れる（「＋ 登録メールアドレス」）
- **ユーザー名** は、ログインに使わない表示名などがある場合だけ入れる（「＋ ユーザー名」）
- **電話番号** は、どの種類でも「＋ 電話番号」で追加できる（以前メモに書いた電話番号は、更新後の初回解除時に自動で電話番号の欄へコピー。メモはそのまま）

### 運用のおすすめ

| やること | 目安 |
|---|---|
| 暗号化バックアップを保存（設定 → 暗号化バックアップを保存 →「ファイル」に保存 / AirDrop） | 登録・変更したとき、または月 1 回 |
| マスターパスワードを紙に書いて自宅の安全な場所に保管 | 作成時・変更時 |
| iOS を最新に保つ | 随時 |
| 平文の書き出しファイルは用が済んだらすぐ削除（「最近削除した項目」からも） | 使ったとき |

- マスターパスワードを変更すると、**古いバックアップは古いマスターパスワードで開きます**。
- コピーしたパスワードは、30 秒経過後の次の操作で消去を試みます。確実に消すには、別の文字をコピーして上書きしてください。

### iPhone が使えないとき

PC のブラウザで同じ URL を開き、「バックアップを開いて見るだけ（保存しない）」から暗号化バックアップを読み込みます。

## 開発

```sh
npm install
npm test            # 暗号・生成器・書き出しの単体テスト
npm run typecheck
npm run build       # docs/ に公開用ファイルを出力
npm run serve       # http://localhost:8080 で確認（別ターミナル）
npm run e2e         # Edge で画面の通し確認（serve 実行中に）
node scripts/make-icons.mjs   # アイコンを作り直すとき
```

- `src/` … アプリ本体（TypeScript）
- `public/` … HTML・CSS・アイコンなどそのまま配信するファイル
- `docs/` … ビルド結果（GitHub Pages はここを配信）。ソースを変えたら必ず `npm run build` してからコミットする。

## 公開（GitHub Pages）

1. GitHub アカウントに **2 段階認証（できればパスキー）** を設定する（配信元を守るため。最重要）
2. GitHub で公開リポジトリ `PassVault` を作成し、このフォルダを push
3. リポジトリの Settings → Pages → Source:「Deploy from a branch」、Branch:`main` / フォルダ:`/docs`
4. 数分後に `https://<ユーザー名>.github.io/PassVault/` で開ける

更新するときは、変更 → `npm test` → `npm run build` → コミット → push。iPhone 側は次回起動時に新しいバージョンを取り込み、その次の起動から反映されます（データはそのまま）。
